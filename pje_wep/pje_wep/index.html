About Me

디자인을 이해하고, 개발로 구현합니다.

디자인과 개발의 연결

저는 컴퓨터공학과 그래픽을 전공하며, UI 구성과 서비스 구현 사이의 연결에 관심을 가져왔습니다.

단순히 화면을 만드는 것보다, 사용자가 어떤 흐름으로 기능을 이해하고 사용하는지 고민하며 그 흐름이 데이터, UI, 배포까지 이어지도록 구현하는 과정을 중요하게 생각합니다.

최근에는 PetLog와 VetFlow를 만들며 AI 분석, 사용자 확인 흐름, Firebase 기반 데이터 구조, Vercel 배포까지 이어지는 웹 서비스 제작 경험을 쌓고 있습니다.
