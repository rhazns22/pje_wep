# 박주은 Portfolio Website

A premium, high-fidelity developer portfolio website showcasing a "Product-Minded Fullstack Developer" persona.

## ✨ Key Features

- **Dark Tech Aesthetics**: Sophisticated dark theme with Mint/Blue accents and Glassmorphism.
- **Product-Centric Case Studies**: Focused on problem-solving flow (Problem -> Solution -> Result).
- **Advanced Interactivity**:
  - Typing effect for Hero.
  - Intersection Observer for scroll-reveal.
  - PC-only Magnetic buttons and Cursor glow.
  - Mobile-optimized horizontal drag & scroll snap.
- **Responsive Design**: Full support for Desktop (1920px), Tablet (768px), and Mobile (375px).
- **Accessibility**: Support for `prefers-reduced-motion`.

## 🛠️ Technology Stack

- **Core**: HTML5, CSS3, Vanilla JavaScript
- **Deployment**: Vercel (Recommended)
- **Tools**: Figma (Design), VS Code
