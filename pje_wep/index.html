AI / Fullstack

PetLog

AI 기반 반려동물 병원비 기록 및 분석 서비스

Problem

반려동물 병원 영수증의 복잡한 항목으로 인해 보호자가 지출 내역을 체계적으로 관리하기 어려움.

Solution

OCR과 Gemini API를 활용해 영수증을 자동 분석하고 지출 항목을 카테고리별로 시각화.

My Role

기획, UI 설계, Firebase 연동, AI 분석 파이프라인 구축 및 프론트엔드 전체 구현.

Result

수동 입력 대비 기록 시간 80% 단축. 베타 테스트를 통해 사용자 편의성 검증.

VetFlow

동물병원 운영 흐름을 실시간으로 관리하는 SaaS 대시보드

Problem

예약, 진료차트, 수납, 입원, 재고, 후속관리 업무가 분리되어 있어 병원 운영 흐름을 즉시 파악하기 어렵습니다.

Solution

Firestore 실시간 데이터와 운영 중심 UI를 결합해, 병원의 오늘 업무 상태와 미완료 작업을 한 화면에서 확인할 수 있도록 설계했습니다.

Key Features

예약 Flowboard, 환자 관리, SOAP 차트, 수납 관리, 입원 모니터링, 재고 알림, CRM 후속관리, 매출 리포트.
