Core Focus

Product Thinking

사용자 문제를 관찰하여 구체적인 서비스 화면 및 기획 단위의 요구사항으로 구체화합니다.

UI/UX Implementation

다양한 디바이스 환경을 고려한 반응형 UI와 명확한 사용자 경험을 만들기 위한 인터랙션을 개발합니다.

Data Integration

API 연동, 사용자 인증 관리, Firebase 기반의 데이터 저장 등 흐름을 다룹니다.

AI & Fallback Flow

AI 분석 API 결과를 실제 서비스 흐름과 연결하고, 오류에 대비한 예외 입력 및 보완 방안을 구성합니다.
